# Stock Price Prediction Using LSTM

## About This Project
This project is part of my learning journey in Machine Learning and Deep Learning.

The objective of this project is to predict stock prices using Long Short-Term Memory (LSTM), a type of Recurrent Neural Network (RNN) that is well-suited for time-series data. LSTM models are effective in capturing long-term dependencies and patterns in sequential data.

This project focuses on understanding how deep learning techniques can be applied to financial time-series data for forecasting.

---

## Objective
The main objectives of this project are:

- Understand time-series forecasting  
- Apply LSTM for stock price prediction  
- Preprocess and prepare financial data  
- Train a deep learning model  
- Evaluate predictions against actual values  

---

## Dataset
The dataset consists of historical stock price data.

It includes:
- Date  
- Open price  
- High price  
- Low price  
- Close price  
- Volume  

Historical data is used to identify patterns and trends for prediction.

---

## Project Workflow
1. Load historical stock data  
2. Perform data preprocessing:
   - Handle missing values  
   - Normalize data using scaling techniques  
3. Convert data into time-series sequences  
4. Build and train the LSTM model  
5. Make predictions on test data  
6. Compare predicted vs actual values  

---

## Model Details
- Model Type: LSTM (Long Short-Term Memory)  
- Framework: TensorFlow / Keras  
- Input: Historical stock prices  
- Output: Predicted future stock prices  

LSTM is suitable for this problem because it can learn patterns over time and handle sequential dependencies in data.
